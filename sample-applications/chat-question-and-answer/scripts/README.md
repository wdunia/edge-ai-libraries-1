# ChatQnA startup script

This script is made to run ChatQnA application using predefined values.
Script will ask for:
- HuggingFace API token
- Target device to run service on

Rest of setup will be done automatically.
Script will attempt to open 3 windows: ChatGPT(left side), ChatQna(Right side) and Prompt box at the bottom of the screen.
Prompt should be submitted to bottom window. this will trigger submission of the same prompt to both apps.
